# 04 — LoRa 射频参数与调试经验

## LoRa 调制参数

### Spreading Factor (SF)

| SF | 芯片/符号 | 比特率 (BW125) | 灵敏度 (dBm) | 传输距离 |
|----|----------|---------------|-------------|---------|
| 7 | 128 | 5470 bps | -123 | 最短 |
| 8 | 256 | 3125 bps | -126 | |
| 9 | 512 | 1760 bps | -129 | |
| 10 | 1024 | 980 bps | -132 | |
| 11 | 2048 | 440 bps | -134.5 | |
| 12 | 4096 | 250 bps | -137 | 最远 |

- SF 每增加 1，传输时间翻倍
- SF 每增加 1，灵敏度提高约 2.5 dB
- 不同 SF 的信号正交（互不干扰）

### Bandwidth (BW)

| BW (kHz) | 说明 |
|----------|------|
| 125 | 标准 LoRaWAN 上行 |
| 250 | 高速率模式 |
| 500 | 用于某些下行或特殊场景 |

BW 越大 → 速率越快 → 灵敏度越低 → 抗多径能力下降

### Coding Rate (CR)

| CR | 冗余 | 抗干扰 |
|----|------|--------|
| 4/5 | 最低 | 最弱 |
| 4/6 | | |
| 4/7 | | |
| 4/8 | 最高 | 最强 |

LoRaWAN 标准使用 CR 4/5。

---

## SyncWord

```
0x34 = LoRa public network (LoRaWAN)
0x12 = LoRa private network (P2P)
```

如果 TX 和 RX 端 SyncWord 不一致，接收端会完全忽略该包（不是 CRC 错误，而是根本不触发解调）。

---

## IQ 反转

LoRaWAN 定义:
- **上行** (节点→网关): 不反转 IQ (`invert_pol = false`)
- **下行** (网关→节点): 反转 IQ (`invert_pol = true`)

这是为了避免同频自干扰。测试时需特别注意两端匹配。

---

## CRC

| 场景 | CRC 设置 |
|------|---------|
| LoRaWAN 上行 | CRC 使能 |
| LoRaWAN 下行 | CRC 关闭 |
| P2P 测试 | 按需设置 |

本项目 HAL TX 测试设置 `no_crc = true`，SX1278 接收端也必须 `setCRC(false)`。

---

## 收发参数匹配清单

TX 端和 RX 端 **必须完全一致** 的参数:

| 参数 | TX 端 (SX1302) | RX 端 (SX1278) |
|------|---------------|----------------|
| 频率 | 486.3 MHz | 486.3 MHz |
| SF | 7 | 7 |
| BW | 125 kHz | 125 kHz |
| CR | 4/5 | 4/5 |
| SyncWord | 0x34 | 0x34 |
| IQ 反转 | false | false |
| CRC | 关闭 | 关闭 |

任何一项不匹配都会导致接收失败。

## RSSI 与 SNR 参考

### RSSI (Received Signal Strength Indicator)

| RSSI (dBm) | 信号质量 |
|------------|---------|
| > -70 | 强信号 (室内近距离) |
| -70 ~ -100 | 正常 |
| -100 ~ -120 | 弱信号 |
| < -120 | 极限灵敏度附近 |

### SNR (Signal-to-Noise Ratio)

| SNR (dB) | 说明 |
|----------|------|
| > 10 | 很好 |
| 5–10 | 良好 |
| 0–5 | 可用 |
| < 0 | LoRa 仍可解调（得益于扩频增益） |
| < -20 | 接近解调极限 |

LoRa 的核心优势：即使 SNR 为负（信号低于噪声），扩频增益仍能解调。

---

## 天线与馈线注意事项

- SMA 接口务必拧紧（松动可能导致 10+ dB 损耗）
- 测试用 470 MHz 天线（不要用 433 MHz 或 868 MHz 天线）
- **绝对不要在无天线时以最大功率发射！** 功放反射波会损坏芯片

## 调试经验

### 看不到任何接收包

排查顺序:
1. 确认 TX 端确实在发送 (用 SDR 或频谱仪验证)
2. 检查频率是否匹配
3. 检查 SyncWord 是否匹配
4. 检查天线是否连接
5. 检查 SX1302 是否正确启动 (`lgw_start()` 返回 0)

### 收到包但 CRC 错误

排查顺序:
1. 检查 BW/SF 是否匹配
2. 检查 IQ 反转是否匹配
3. 距离太远导致信号衰减 → 降低 SF 或减小距离

### RSSI 正常但丢包率高

可能原因:
- 同频干扰 (附近有其他 470 MHz 设备)
- 多径效应 (室内反射)
- TX 端发射间隔太短，RX 端来不及处理
